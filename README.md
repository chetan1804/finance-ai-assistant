# Finance Assistant

An AI-powered personal finance assistant that understands the user's
financial data, spending behavior, goals, and preferences.

## Project Vision

Build a finance assistant progressively using:

- Python
- Data Analysis
- Machine Learning
- Generative AI
- RAG
- LLMs
- Tool Calling
- Agentic AI
- LangChain
- LangGraph
- Evaluation
- Production deployment
